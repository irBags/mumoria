# mumoria

The Dungeons of Moria is a single player dungeon simulation originally written by Robert Alan Koeneke, with its first public release in 1983.
The game was originally developed using VMS Pascal before being ported to the C language by James E. Wilson in 1988, and released as Umoria.
Mumoria is a port of Umoria into a MMORPG, complete with banks, guilds, groups, a global auction house ( AH ), and persistent maps, including world chat, and guild/group chat systems. 2026 Mike Killingbeck
